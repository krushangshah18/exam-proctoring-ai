# 🧠 Color Usage Rules

## 1. 60–30–10 Rule

- 60% → Background (white/gray)
- 30% → Surfaces/cards
- 10% → Colors (blue/teal/green)

---

## 2. One Color = One Meaning

- Blue → Primary actions
- Teal → Interaction / hover
- Green → Success / safe

⚠️ Never mix meanings

---

## 3. Avoid Bright Backgrounds

❌ Full colored sections  
❌ Bright cards

✅ Use white/gray base + subtle accents

---

## 4. Color = Communication

- Green → Safe
- Yellow → Suspicious
- Red → Cheating

⚠️ Must remain consistent across UI

---

## 5. Maintain Contrast

- Minimum contrast ratio: **4.5:1**
- Avoid light text on light colors

---

## 6. Component States (Required)

### Primary Button Example:

- Default: `#22577A`
- Hover: `#2C6A91`
- Active: `#1B455F`
- Disabled: `#64748B`
